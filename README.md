# Simple Login Application

A simple user creation and login application with oauth options.

## Steps to run repo:

- git clone https://github.com/craigstroman/simple-login-app-client.git
- cd simple-login-app-client
- Run `npm install` or `yarn install`
- Create database in PostgreSQL and set database password, add database user, set password in .env file
- Run `npm run live:server` or `yarn run live:server` to start development environment
- Then go to http://localhost:9000/graphql
